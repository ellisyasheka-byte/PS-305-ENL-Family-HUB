# PS 305 Family Hub

The PS 305 Family Hub is a resource created to support PS 305 students and families.

The Hub provides easy access to:
- Learning and language practice resources
- Reading support
- Parent and family information
- Family workshops and presentations
- WIDA information and resources
- Educational videos
- Additional resources to support learning at home

## Purpose

The Family Hub is designed as an additional place for students and families to find support and practice. It does not replace classroom instruction, homework, or daily reading.

The Hub will continue to grow as new resources, family workshops, videos, and learning supports are added throughout the school year.
